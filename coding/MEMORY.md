# Coding Memory

자신의 개발·자동화 작업에 재사용할 **비민감 장기 기억 색인**입니다.

## 역할

- 반복된 구현·테스트·배포·검토 패턴
- 여러 프로젝트에 적용되는 판단 원칙과 재발 방지 교훈
- 비민감한 도구·환경 지식

현재 코드·버전·PR·커밋·프로젝트별 설계의 정본은 자신의 `coding` 저장소와 해당 README입니다. 토큰, 개인정보, 운영 로그, 비공개 payload를 기록하지 않습니다.

## 예정 하위 영역

필요할 때만 `projects/`, `workflows/`, `decisions/`, `knowledge/`, `history/`를 만듭니다.

## Index

등록된 실제 기억이 없습니다. 필요할 때만 항목과 상대경로 링크를 추가합니다.
