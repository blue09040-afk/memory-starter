# m1 Memory

자신의 행정문서·민원·감사 등 `m1` 업무에 재사용할 **비민감 장기 기억 색인**입니다.

## 역할

- 확인된 문안·형식 선호와 반복 수정 패턴
- 비식별 일반 업무지식·검토 방법
- 사건 고유 사실이나 프로젝트 지침을 대체하지 않는 재사용 맥락

개인정보·사건번호·내부 문서번호·비공개 원문·공문/회신문 전문은 저장하지 않습니다. 관찰·신뢰도·지침 승격은 사용자 자신의 `m1` 지침을 따릅니다.

## 예정 하위 영역

실제 필요할 때만 `preferences/`, `workflows/`, `knowledge/`, `projects/`, `history/`, `candidates/`를 만듭니다.

## Index

등록된 실제 기억이 없습니다. 파일을 추가할 때 기존 항목과 중복을 확인하고 이곳에 상대경로로 연결합니다.
